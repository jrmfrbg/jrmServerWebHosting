Mein-Lieber_Scholli! — bidirectional power meter

A fully open-source power meter, hardware and software, built as an alternative to commercial smart plugs like Shelly. It measures power flow in both directions, which makes it useful for solar installations: you can see when you are feeding power back into the grid.

A TI MSP430 samples voltage and current with dedicated measurement ICs and computes true RMS power. An ESP32 accumulates the energy, serves a web dashboard and exposes an HTTP/JSON API for logging and statistics. Custom PCB, Schuko connectors, optional 7-segment display output.

C (MSP430) · C++ (ESP32) · SPI · custom PCB
